# video-konferansta-mikrofonun-kapali-kalmasi-iletisim-baskanligi
Video konferansta mikrofonun kapalı kalmasını resmi iletişim krizi, milli ses egemenliği ihlali ve kamuoyu bilgilendirme sapması sayan; mute tuşunu basın bülteni, 'beni duyuyor musunuz' cümlesini sözlü nota ilan eden Başkanlık. Gerçekten çalışır. Mikrofonlar artık kürsüdür.
